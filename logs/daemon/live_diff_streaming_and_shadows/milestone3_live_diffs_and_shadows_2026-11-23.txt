2. WORK PERFORMED & ARCHITECTURE DETAILS
   - `@nucleus/daemon`:
     * `shadow/peers-index.ts` (`PeersIndexManager`):
       - Renders live markdown table with lane, node ID, status, and active file focus.
       - Generates explicit instructions for AI coding agents (Claude Code, Antigravity, Aider)
         directing them to check `.nucleus/shadows/<lane>/` instead of guessing payload shapes.
     * `shadow/shadow-mirror.ts` (`ShadowMirror`):
       - Safely writes peer lane uncommitted files inside the workspace jail under `.nucleus/shadows/<lane>/`.
       - Implements version monotonicity enforcement to ignore stale out-of-order frames.
     * `watcher/diff-watcher.ts` (`WorkspaceDiffWatcher`):
       - File-watcher with debouncing (300ms) excluding `node_modules`, `.git`, `.nucleus`, `dist`.
       - Detects edits and calculates lightweight line delta summaries and diff hunks.
     * `client/daemon-client.ts`:
       - Added `streamDiff`, `notifyFocusChange`, and `syncLaneShadow` wire emitters.
   - `@nucleus/coordinator`:
     * `server/coordinator-server.ts`:
       - Handled `sharing:file_focus_change` to update in-memory registry and fan out focus events.
       - Handled general `sharing:*` fanout to all active room peers.
   - Integration tests in `packages/coordinator/src/server/sharing.integration.test.ts`:
     * Verified `.nucleus/PEERS.md` generation and active file focus updates.
     * Verified live cross-lane shadow sync without touching Git remotes.
     * Verified workspace change detection and diff hunk generation.

3. WHY BEHIND THE CHANGE
   - Zero Git Friction for In-Progress Work: Teammates and their agents see API and component
     structures taking shape in real time without creating throwaway Git commits.
   - Passive Context Injection: AI coding tools cannot connect to arbitrary WebSocket feeds,
     but naturally read workspace files. `.nucleus/PEERS.md` bridges the gap.
