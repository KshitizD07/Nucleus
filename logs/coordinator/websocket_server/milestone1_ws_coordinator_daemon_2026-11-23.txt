   - Integration test: `coordinator.integration.test.ts` verifies join and token rejection paths.

3. WHY BEHIND THE CHANGE
   - Single-use tokens and consume-on-use pattern prevent replay attacks against room join.
   - JSONL append-only event log enables coordinator crash recovery without a database.
   - Heartbeat-based eviction (20s timeout) ensures stale nodes release contract leases automatically.
   - Daemon never spawns or wraps user CLI — all network activity is room-side coordination only.

4. WHY NOT THE ALTERNATIVE(S)
   - Alternative: Session tokens persisted to DB
     * Why Rejected: Adds infrastructure complexity before proving the network layer. JSONL replay
       handles crash recovery adequately for Phase 1.
   - Alternative: Persistent TCP or HTTP long-polling
     * Why Rejected: WebSocket provides native bi-directional framing suited for real-time
       event fanout without HTTP overhead on each message.
