3. WHY BEHIND THE CHANGE
   - Central Contract Mutex: Guarantees no two lanes diverge on shared APIs or database schemas simultaneously.
   - Monotonic Versioning: Coordinator serves as single source of truth for versions, rejecting stale updates.
   - Jail Containment: Ensures incoming broadcast updates never write outside the workspace jail.

4. WHY NOT THE ALTERNATIVE(S)
   - Alternative: Git branch merge for contract updates
     * Why Rejected: Merging a Git branch takes minutes; contract synchronization needs sub-second latency
       so parallel builders don't write code against obsolete schemas.
   - Alternative: Permanent lock until manual release
     * Why Rejected: If a contributor's machine crashes or disconnects while editing a contract, the room
       would deadlock. 15-second renewable leases solve this safely.
