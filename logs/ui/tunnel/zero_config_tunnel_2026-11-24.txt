1. OBJECTIVE
   - Implement native zero-config public tunneling fallback in the developer CLI.
   - Allow remote contributors on separate subnets / isolated networks to connect via `wss://` URLs generated by Cloudflare Tunnels (`cloudflared`) or ngrok with `--tunnel`.

2. WORK PERFORMED & ARCHITECTURE DETAILS
   - Created `TunnelManager` in `packages/cli/src/tunnel/tunnel-manager.ts`:
     - Spawns `cloudflared tunnel --url http://localhost:<port>` and extracts the public `trycloudflare.com` subdomain, converting it to an internet-routable `wss://` invite endpoint.
     - Falls back to `ngrok http <port>` querying local inspect API (`http://127.0.0.1:4040/api/tunnels`) if `cloudflared` is unavailable.
     - Provides clean graceful process lifecycle termination on `runner.stop()` / SIGINT.
     - Supports injection of custom or pre-configured `tunnelUrl` for testing and deterministic environments.
   - Updated `packages/cli/src/args.ts`: added `--tunnel` flag and CLI help documentation.
   - Updated `packages/cli/src/commands/init.ts` (`InitRunner`): added `startTunnel()`, `stop()` process cleanup, and `tunnelUrl` export.
   - Updated `packages/cli/bin/nucleus.js`: prints remote internet invite commands (`wss://<subdomain>.trycloudflare.com`) when `--tunnel` is enabled.
   - Added unit and integration tests in `packages/cli/src/cli.test.ts`.

3. WHY BEHIND THE CHANGE
   - Developers frequently work from office, university, coffee shop, or cloud environments with Wi-Fi client isolation or NAT boundaries that block direct LAN IP routing (`192.168.x.x` / `10.x.x.x`).
   - Requiring manual router port forwarding or third-party web tunneling with anti-bot captcha interstitials breaks WebSocket connections and adds onboarding friction.

4. WHY NOT THE ALTERNATIVE(S)
   - Localtunnel / pagekite: Injects anti-bot challenge headers and interstitial landing pages that terminate raw WebSocket handshakes.
   - Mandating VPN (Tailscale/WireGuard): Requires teammates to install root-level network drivers and share private virtual networks. `cloudflared` provides ephemeral zero-login public tunneling.
