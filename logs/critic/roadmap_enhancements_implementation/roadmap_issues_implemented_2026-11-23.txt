   - Transform the pending roadmap items identified in the architecture audit into

   - Issue 1 (Daemon Auto-Reconnect):
     * Added `autoReconnect` option (default: true) and exponential retry backoff
       (500ms, 1000ms, 2000ms up to 30,000ms max) in `packages/daemon/src/client/daemon-client.ts`.
     * Added `onReconnect` hook. Verified intentional `sever()` does not trigger retry loops.
     * Added unit test in `daemon-reconnect.test.ts`.
   - Issue 2 (CLI Task Subcommands):
     * Created `packages/cli/src/commands/tasks.ts` with `listTasks` and `claimTaskLocally`.
     * Updated `packages/cli/src/args.ts` to parse `nucleus tasks` and `nucleus claim <task_id> [--name <name>]`.

     * Added CLI test verifying local `.nucleus/tasks.json` mutation in `cli.test.ts`.
   - Issue 3 (Deterministic Secret Scanner):
     * Created `packages/critic/src/scanner/secret-scanner.ts` with default regex rulesets
       for Private Keys, AWS Access Keys, Stripe Secret Keys, and generic password assignments.
     * Generates structured `CriticFindingItem` records with severity `"critical"`.
     * Added test suite in `secret-scanner.test.ts`.
   - Issue 4 (Proactive Lease Alerts):
     * Added `isExpiringSoon(filePath, thresholdSeconds)` and `getExpiringLocks(thresholdSeconds)`
       in `packages/coordinator/src/lock/mutex.ts` to alert nodes before automatic release.
     * Added unit tests in `mutex.test.ts`.
   - Issue 5 (Pluggable AI Critic Pipeline):
     * Created `packages/critic/src/reviewer/ai-critic.ts` defining `LLMCriticProvider` interface.
     * Implemented `StaticRuleCriticProvider` and `AICriticPipeline` evaluating Stage 1 checks
       and Stage 2 generative reviews into formatted markdown.
     * Added test suite in `ai-critic.test.ts`.

3. WHY BEHIND THE CHANGE
   - Network Resilience: Auto-reconnect protects against unstable Wi-Fi connections.
   - Developer Ergonomics: `nucleus claim` and `nucleus tasks` enable quick task claims from any terminal tab.
   - Defense-in-Depth: Automated secret scanning prevents accidental credential commits before merge.
   - Extensibility: Pluggable AI critic interface allows swapping between mock rulesets and live LLM endpoints.
