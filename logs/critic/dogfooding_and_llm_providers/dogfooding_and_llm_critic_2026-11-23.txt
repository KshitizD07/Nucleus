3. WHY BEHIND THE CHANGE
   - Production Grade Architectural Gate: Static checks detect format, build, and regex secrets;
     generative LLMs detect subtle architectural contract divergences, missing validation, or schema mismatches.
   - Project Customization: Teams need to instruct AI agents on repo-specific coding conventions (e.g.
     "always run typecheck", "use strict error envelopes").
   - Internet Accessibility: Room hosts frequently want remote friends to collaborate without complex router
     port forwarding. Printing Cloudflare Tunnel / Tailscale options eliminates networking friction.
   - Verification Rigor: Dogfooding multi-lane simulation guarantees all 5 packages work cohesively under
     real concurrent operational scenarios.

4. WHY NOT THE ALTERNATIVE(S)
   - Alternative A (Enforce hard dependency on Gemini or Anthropic SDKs):
     * Rejected: Adding `@google/genai` or `@anthropic-ai/sdk` bloats node_modules and introduces
       potential version conflicts. Using Node 22 native ESM `fetch` with lightweight payload schemas
       keeps the footprint minimal and fast.
   - Alternative B (Force manual port forwarding in routers):
     * Rejected: Most developers work behind CGNAT or home Wi-Fi where router admin access is inaccessible
       or cumbersome. Tunnel guidance (Cloudflare Tunnel, Tailscale) provides instant WAN access.
   - Alternative C (Hardcoded monolithic PEERS.md instructions):
     * Rejected: Repositories have distinct conventions. Dynamic template ingestion gives teams full autonomy.
