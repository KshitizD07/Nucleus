3. WHY BEHIND THE CHANGE
   - Zero Working Tree Pollution: Checking out contributor PR branches directly on the Initiator's
     machine disrupts ongoing local work and risks unstaged file loss. Git worktrees solve this
     with disposable, zero-copy checkouts.
   - Pull-Model Critique: Generating a markdown artifact in `.nucleus/critiques/` allows the contributor's
     local AI agent to fix issues autonomously by simply reading the file.
